# fitointer-sus

## Arquivos que precisam ser baixados

Alguns arquivos de dados são grandes demais para o repositório e não estão no git. Baixe-os antes de rodar os scripts.

### `dados/relationships.tsv` (ClinPGx)

Usado por `cruzamento_RENAME_enzimas.py`.

1. Acesse o site do ClinPGx (clinpgx.org) e abra a página **Downloads**.
2. Baixe o arquivo **relationships.zip** (pode ser preciso aceitar a licença de uso).
3. Extraia o `relationships.tsv` e salve-o na pasta `dados/`.
